# 采用“获焦触发 + 混合剪贴板适配 + 分层置信度 DAG + 隐私零读取护栏”的智能识别架构

V1 的 **智能识别（Smart Detection）** 采用 **零后台轮询、主工作台获焦触发 + 显式智能粘贴（`Ctrl/Cmd+Shift+V` / 工作台首页 `Ctrl/Cmd+V`）双通路**；底层通过混合剪贴板适配层按 `Files > Image > Text` 读取（Windows/macOS 优先 `arboard 3.7` 补齐重试、多格式防吞图、文件列表与隐私写标记，Linux 获焦优先走 GPUI 内置读以兼容 GNOME Wayland，按需辅以 `arboard`）；探测内核构建在零 GPUI 依赖的纯 Rust 后台并发 **分层置信度 DAG** 上（叶子覆盖父级、保留完整路径强类型载荷、显式互斥压制、按 `ToolId` 去重、硬超时 300 ms），并在读取剪贴板正文前强制执行 OS 密码管理器隐藏标记零读取跳过、高危私钥静默保护与 256 KB / 2 MB / 20 MB 分级截断。选用该架构是因为后台轮询剪贴板会违背零剪贴板历史红线、触发 macOS 15.4+/26 `NSPasteboard` 隐私同意弹窗并在 GNOME Mutter Wayland（无 `ext-data-control` 协议）彻底失效，而强类型路径 DAG + 显式置信度与压制规则从根源上消除了 `DevToys 2.0` 的父子类型回退错配、兄弟冲突无序、串行阻塞与 Windows 路径/短词误判缺陷。

## Considered Options

- **后台常驻监听/轮询系统剪贴板**：虽可在唤起前提前完成计算，但会频繁触发 macOS 15.4+/26 `NSPasteboard` 隐私权限弹窗、在 GNOME Wayland 上无法工作，且与 V1「不做后台剪贴板历史管理器」的隐私基线正面冲突，排除。
- **全平台仅使用 GPUI 内置 `Clipboard` 或全平台仅使用 `arboard 3.7`**：仅用 GPUI 内置会命中 macOS 文本吞图短路、缺少 Windows 占用重试、缺少 HTML/Linux 文件列表且无法写入排除剪贴板历史的隐私标记；仅用 `arboard` 则在 GNOME Wayland 缺少 `data-control` 协议支持导致读剪贴板失效，故采用三端混合适配层。
- **扁平正则列表 + 唯一命中强制自动跳转**：扁平列表在 `JWT` / `Base64` / `JSON` / `YAML` / `EscapedText` 等存在包含关系的格式上会产生大量重复与随机顺序冲突；在多标签主工作台中无条件强制跳转会劫持并打断用户当前编辑现场，排除。
- **携带识别数据打开工具时直接覆盖已有工具标签页**：容易静默丢失用户正在编辑的未清空输入，排除；改为「空标签页复用、非空标签页自动新建独立工具标签页实例」。

## Consequences

- **纯 Rust 探测内核契约锁定**：`Detector` 须为无状态纯 Rust 组件（零 GPUI 依赖），声明父子 `DataType` 依赖、返回带 `Confidence`（`Exact`/`High`/`Medium`/`Low`）的强类型载荷，引擎保留整条匹配路径供不同层级工具精准提取对应类型，确保未来可无损复用于 CLI 或单元测试。
- **平台剪贴板与隐私边界明确**：
  - 任何自动剪贴板读取必须在主工作台获焦后异步执行，且先检查 OS 隐藏标记（macOS `ConcealedType`/`TransientType`/`AutoGeneratedType`/`1Password`、Windows `ExcludeClipboardContentFromMonitorProcessing`/`CanIncludeInClipboardHistory == 0`、Linux `x-kde-passwordManagerHint=secret`），命中即零读取跳过；
  - 维护内存态剪贴板指纹去重与「自我复制抑制」标记，确保 `DevTools` 自身复制不会触发自推；密码/JWT/Hash 等敏感结果复制默认通过 `arboard` 写入排除系统剪贴板历史标记；
  - macOS 15.4+/26 拒绝自动检测授权或用户关闭总开关时，通过工作台首页 `Cmd+V` 与全局 `Cmd+Shift+V` 提供零系统弹窗的完整降级体验。
- **非侵入推荐与单跳工具接力统一引擎**：剪贴板 `strict` 模式默认仅以顶栏轻提示条（≤ 3 项）+ 快速命令面板置顶（≤ 5 项）+ 侧边栏全位置高亮呈现（自动跳转为默认关闭的可选设置）；只读输出区「工具接力（Tool Relay）」复用同一套 DAG 引擎（`relay` 模式，排除自身并追加一级父类型兼容工具），绝不演变为多节点管道。
- **性能与大负载硬底线**：全量探测在后台线程池并发执行，硬超时 **300 ms**（慢探测器独立取消不拖累快路径）；文本 > 256 KB 降级 64 KB 魔数嗅探、> 2 MB 跳过自动探测；图片探测期仅读头部元数据且 > 20 MB 延迟加载；单文件 > 100 MB 仅匹配流式哈希等工具。
